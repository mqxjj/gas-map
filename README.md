# gas-map

2026版全国天然气一张图。

## 功能

- 全国视图：31 省区市天然气干线分布、悬停高亮途经管线
- 省份视图：自动缩放居中显示该省干线，分省级干线与市域干线
- 省份面板：显示 2025 年官方天然气消费量、统计来源、公开线路覆盖
- 数据来源：国家能源局《中国天然气发展报告（2026）》、各省统计局/能源主管部门公开资料
- A3 高清全国图：4961 × 3508 像素

## 说明

- 管道路由依据公开起止点、途经地及环评节点连线，非工程测量成果
- 省级天然气消费量为天然气消费量口径，不等于长输管道实际输气量
- 不含油田自用、管道自耗及部分液厂用气（国家能源局报告附注口径）
